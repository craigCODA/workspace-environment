# Workspace Environment

A Windows-first spatial workspace where the PC remains the authoritative computer and spatial clients provide alternate ways to see, organize, and operate real applications, files, projects, processes, and persistent workspace objects.

The canonical design is currently in:

- `docs/superpowers/specs/2026-09-07-workspace-environment-design.md`

Implementation has not started yet. The design is intentionally frozen first so the Windows host, spatial client, Quest path, and agent boundary do not collapse into one application.
